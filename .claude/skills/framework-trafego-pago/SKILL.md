# Framework de Raciocinio PPC

## A Cadeia de Alinhamento

Todo elemento no Google Ads deve se alinhar em cadeia:

**Intencao de Busca → Palavra-chave → Anuncio → Pagina de Destino → Acao de Conversao**

Se qualquer elo quebra, a performance cai. Ao auditar ou otimizar, sempre verifique a cadeia completa.

## Hierarquia de Rentabilidade

Avalie tudo por esta otica (em ordem):

1. **Esta convertendo?** (taxa de conversao, volume de conversoes)
2. **Esta lucrativo?** (CPA vs meta, ROAS vs meta)
3. **E escalavel?** (parcela de impressao, margem de orcamento)
4. **E eficiente?** (Quality Score, CTR, gasto desperdicado)

## Principios

- **Dados, nao opinioes.** Sempre puxe os numeros reais antes de recomendar.
- **Especificidade.** "Pausar keyword X que gastou R$2.200 com 0 conversoes" e melhor que "revisar keywords de baixa performance."
- **Ordem de impacto.** Priorize por: (gasto em risco) x (chance de melhoria).
- **Contexto importa.** Um CTR de 5% pode ser otimo para seguros e pessimo para termos de marca. Sempre considere o nicho e tipo de campanha.
- **Nao mexa no que funciona.** Sempre destaque os top performers e sinalize como "nao alterar."

## Limites Estatisticos

Antes de tomar decisoes, garanta dados suficientes:

| Gasto Mensal | Periodo Minimo | Cliques Min. p/ Decisao |
|---|---|---|
| Ate R$25k | 60-90 dias | 50+ cliques |
| R$25k-R$125k | 30-60 dias | 30+ cliques |
| R$125k-R$500k | 14-30 dias | 20+ cliques |
| R$500k+ | 7-14 dias | 15+ cliques |

Nunca pause uma keyword com menos cliques que o minimo, a menos que seja claramente irrelevante.
